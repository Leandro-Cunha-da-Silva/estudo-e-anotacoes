Picture

Aqui vamos ver como deixar nossas imagens responsivas usando a tag "picture".

Prints

  • W3Schools

Dentro dessa tag teremos o "media= (min-width: ) ou (max-width: )"" para especificar os tamanhos que queremos em nossas imagens.

Uma coisa para ter atenção é: quando for colocar o caminho da imagem no "sercset" você precisa colocar o caminho todo manual. Aqui não tem autocomplete e por isso precisamos ter atenção para quando for colocar o caminho da imagem ou o link. Se for link é só copiar e colar, quando for imagem precisa colocar o caminho todo até a imagem. Ex.: "./src/img/01-tag-picture-mob-e-desk.png".
