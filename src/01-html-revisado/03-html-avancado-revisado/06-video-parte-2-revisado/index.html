Alguns navegadores não aceitam vídeo em MP4 então precisamos colocar o código da seguinte forma e precisamos converter os vídeos para os formatos a seguir.

Site para fazer a conversão dos formatos de vídeos: Convertio

Desvantagens:

Como falado na "Parte - 1", usar a tag 'video' para carregar vídeos de uma biblioteca própria é rui porque os vídeos são pesados e ocupam muitos megas de espaço. Para isso teremos muitos gastos no servidor para armazenar tudo e toda vez que o usuário carregar nosso vídeo teremos gastos por causa dessa transação de banda. Além disso o usuário final também acaba usando muita internet para carregar nosso vídeo se por exemplo ele estiver usando um celular sem wifi.

Melhor que o cliente para quem estamos fazendo o trabalho suba seus vídeos para o Youtube ou Vimeo. Depois usando Iframes colocamos o vídeo no projeto.
Assim fica muito melhor para o usuário final e o cliente que não vai gastar com hospedagem de vídeo em servidor próprio.

Uma desvantangem do Youtube é que ele não permite usar iframes para vídeos privados. Se essa for uma necessidade do cliente teremos que usar outros provedores como o Vimeo que permite fazer isso.
