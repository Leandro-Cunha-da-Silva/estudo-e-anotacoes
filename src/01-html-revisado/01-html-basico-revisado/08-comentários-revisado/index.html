Comentários de Códigos

A linha a baixo mostra que aqui foi adicionado um comentário. Um comentário não é visto no código final, o que é mostrado na tela para o usuário, então aqui podemos colocar algumas observações que outros devs verão e terão um entendimento do que foi escrito em um código, por exemplo:

Para usar um "comentário" escrevemos o texto depois selecionameos ele e pressionamos (Ctrl + : ) para comentar.:

  • (< ! --Aqui é um texto comentado -- >)
  • Quando comentado o texto vai aparecer assim, mas em cor escura.

Não é ideal que se use muitos comentários, um bom código, bem escrito, não precisa disso apenas se for algo muito específico. Mas é bom evitar, e escrever um código compreensível que não tenha necessidade de colocar comentários.

Usaremos aqui para fins de aprendizado, porque no código real usaremos pouco ou de preferência nenhum.
