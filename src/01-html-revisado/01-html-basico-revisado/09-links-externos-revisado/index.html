Links

Aqui aprendemos como utilizar links para levar para outras páginas. Não devemos esquecer de usar o target="_blank" para abrir o link em outra aba do navegador. Dessa forma o usuário sempre vai ficar na nossa página principal, vai lá no link aberto ver o que quer e retorna apenas selecionando a aba da nossa página que ficou aberta em seu navegador.
