Meta Tags

Nas meta tags não precisa ter fechamento já que são apenas definições da página.

Meta tags são compostas de atributo e valor. Exemplo:

  • (meta charset(atributo) = UTF-8(valor))

Podemos criar várias meta tags e o que vai definir cada uma são os atributos e valor que colocaremos em cada uma delas.

-Primeira Meta tag.

  • UTF-8 é um padrão 'unicode' que serve para identifica qualquer idioma de onde a pessoa esteja acessando nossa página. Se essa tag for trocada, vai da erro quando escrever determinadas palavras já que em alguns idiomas mudam as acentuações ou nem possuem acento nas palavras.

-Segunda Meta Tag:

  • (name="viewport") Essa tag vai fornecer para o navegador como controlar as dimenssões e a escala da nossa página.
  • (content="width=device-width") Esse atributo e valor define a largura da página que vai se adequar a largura do dispositivo que estará acessando o site.
  • ("initial-scale=1.0") Esse atributo e valor define o nível de zoom inicial que a pagina vai ter quando acessarmos ela.

-Terceira Meta Tag

  • (name="description") Serve para descrever o que é nossa página.
