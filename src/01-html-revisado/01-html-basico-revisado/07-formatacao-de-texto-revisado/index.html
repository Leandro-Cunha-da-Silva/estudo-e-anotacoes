Formatação de texto

Essa página possui um texto a ser formatado

Esse texto vai ser em: negrito

  • Usaremos sempre o "strong" ao invés de "b = bold" para da mais relevância a nosso texto e isso ajuda no buscador já que o bot entende essa tag como sendo mais importante e oferece nossa página na hora da busca.

Esse texto vai ser em: itálico

  • Aqui usamos a tag "< i >"

Esse texto vai ser em: sublinhado

  • Aqui usamos a tag "< u >"

Esse texto vai ser em: taxado

  • Aqui usamos a tag "< s >"

Atenção!

Não é recomendado utilizar essas tags apenas para fins estéticos. Para isso usaremos o CSS que é uma linguagem de estilos, já que o HTML não é para isso e sim para marcação.
