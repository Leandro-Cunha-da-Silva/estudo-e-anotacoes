Historia

  • Como surgiu:

    Surgiu nos laboratorios da CERN que é uma organização para pesquisa nuclear em Geneva, na Suiça.

  • Criador:

    Tim Berners-Lee e Roberto Cailliau. A ideia do Tim era facilitar a troca, o agrupamento e a atualização de documentos. Ele queria isso para pesquisadores do mundo todo porque era muita informção apenan para o Tim dar contar.

  • Texto ao qual se agregam outros conjuntos de informação, os famosos links
  • Troca, agrupamento e atualização de informações de documentos;
  • Uma bagunça:

    Na epoca não existia um padrão para trabalhar com HTML, cada navegar renderizava do seu jeito o que deixava tudo muito trabalhoso e bagunçado.

    Nessa época surgiu uma organização chamada W3C (World Wid Web Consortium) para padronizar isso e deixar mais fácil. Assim os programadores da época poderiam escrever um código só e isso iria rodar em todos os navegadores sem problemas.

  • Outras versões de HTML:
    • HTML 2.0 / 1995
    • HTML 3.2 / 1997
    • HTML 4.01 / 1999
    • HTML 5 / 2008 (esse usamos até hoje)
