Nessa aula vamos aprender como criar uma tabela. Começamos com a tag "table" para formar a estrutura base da tabela, com essa tag a gente informa para o sitema que queremos fazer uma tabela. a tag "thead" define o cabeçalho da tabela, ainda no cabeçalho usaremos o "tr" para fazer uma linha e "th" para escrever o que queremos no cabeçalho da tabela.

A tag "tbody" é o corpo da nossa tabela, fazendo assim nossa tabela fica melhor organizada e quando for para modificar ela, fica mais fácil usando essa tag para juntar cada parte da tabela em seu devido lugar.

No corpo da tabela (tbody) usaremos o "tr" para linhas e o "td" para cada item que queremos nela.

Tabela 01

Nome Idade Informações adicionais
Leandro 29 Desenvolvedor
Damiana 27 Vendedora
Daniel 30 Automação industrial
Gabriel 29 Fotógrafo

Nas tabelas podemos colocar atributos para expandir/esticar uma linha para que ela ocupe outras colunas. Como por exemplo o atributo 'colspan', esse atributo colocaremos dentro do elemento "td" (colspan="2") para esticar a linha para duas colunas ou mais. O valor é sempre correspondente ao número de colunas que temos em nossa tabela, se nossa tabela tem 20 colunas podemos colocar "=20", mas no caso do exemplo aqui temos apenas 4 colunas e se colocarmos o valor maior que isso nada acontecerá já que não em espaço para tanto.

Temos também o "rowspan" que expande/estica o número de linhas que o item vai ocupar. A funcionalidade é parecida com o "colspan" só que ao invés de colunas estica as linhas e também colocaremos dentro do "td rowspan="2".

Temos também o "tfoot" que serve para fazer um rodapé para nossa tabela. Ele serve para da informações final como soma total de intem ou valores. Nesse exemplo usei o "tfoot" para colocar uma linha com o valor total dos itens e para esticar a linha do 'total' usei o "td colspan="3". Esses componentes usaremos conforme a necessidade de cada tabela.

Tabela 02

Produtos Quantidade Preço Back Friday
Produto 1 2 R$ 5,00 Sim
Produto 2 5 R$ 10,00 Sim
Produto 3 3 R$ 15,00 Não
Total R$ 30,00

Para deixar as tabelas com a bordas bonitinhas igual no exemplo podemos usar a seguinte estilização no css
"table, th, td {
border: 1px solid black;
}"
