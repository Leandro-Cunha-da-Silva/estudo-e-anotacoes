Criação da primeira página HTML

Primeiro vamos entender qual é a estutura base para a criação de uma página HTML

A imagem abaixo ilustra bem isso:

Aqui no exemplo que temos na imagem o (html) engloba tudo, ele é o copo da página.

O (head) é a cabeça da nossa página que é onde ficam as metas tags, links para outro arquivos como por exemplo link para a pasta src onde ficam o css (estilos, reset, responsive), javascript, imagem e outros. Aqui é onde fica também o título da página.

O (body) é onde ficam as tags da página, é onde fica o que vai aparecer para o usuário. Toda a estrutura que o usuário vai ver e usar está aqui dentro.
