Imagens

Aqui vamos ver como colocar imagens em nosso projeto. o "src" é onde fica a imagem que queremos já o "alt" é o texto alternativo que aparece em caso de erro, se por algum motivo a imagem não carregar como deveria vai aparecer o texto que colocaremos ali.

Outra coisa que podemos colocar é o "title" que ao colocar o mouse em cima da nossa imagem vai aparecer o nome que você escolher para ela.

Bônus nessa aula! Podemos também colocar imagem de links externos na nossa página.
