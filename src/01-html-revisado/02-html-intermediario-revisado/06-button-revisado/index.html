Button

Aqui veremos a tag "button" e o "input type=button".
Para criar o button escrevemos assim: (< button > Clicar aqui < /button>)
Um button pode ser criado para alguns fins como por exemplo, exibir uma animaçção na tela, mostrar um aletar ou ir para algum lugar.



Para criar o input type=button escrevemos assim: (< input type="button" value="Clicar aqui" onclick="alert('surimanta')">)
Aqui temos o button, um valor "value=clicar aqui" que é o texto que aparece dentro do button e o "onclick=alert()" que é a ação de mostrar um alerta quando clicar nesse button.

Mas, quando usar um ou outro?
A tag "button" é mais semântica então usa-lá é melhor. Olhando para os dois não tem diferença, visualmente falando, mas é bom usar o button por ser semântico.
