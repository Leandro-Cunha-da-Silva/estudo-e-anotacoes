Anatomia do Input e Input Text

Para começar escrever uma tag de 'input' precisamos escrever primeiro "input" e logo em seguida dizer que tipo de input estamos fazendo como por exemplo (input type="text").
Também podemos dizer que tipo e texto será passando um atributo para ele, nome ou e-mail, por exemplo: (input type="text" name="nome" ou "name="e-mail"").
Isso serve para facilitar o uso pelo usuário final ou até mesmo para quando enviar para o back-end sabermos o que está indo para lá.
Dessa forma o servidor vai conseguir identifcar o que é cada coisa.
Outro atributo que podemos colocar é o "value" que é o valor do campo, podemos definir um valor ou deixar em branco. Se por acaso colocarmos um valor aqui "value="desenvolvedor""
isso irá aparecer no campo do texto dentro do input quando abrir a página ou apertar um F5, mas quando o usuário digitar o que ele quer e enviar isso para o back-end então o valor será sobrescrito.
Outro atributo é o "id" que é o identificador desse campo, isso é importante para depois caso for criar um "label" para essa parte.
