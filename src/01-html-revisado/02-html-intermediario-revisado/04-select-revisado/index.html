Select

Aqui veremos a tag "Select" que serve para selecionar um ou mais valores para enviar para o back-end por exemplo.
Para escrever a tag vamos usar o (select - com abertura e fechamento de tag) e dentro do select vamos colocar as opções que o usuário vai poder selecionar quando estiver aqui.
Dentro do já criado "select" vamos colocar um "option" seus atirbutos e valores:
(select
option value="senhor dos anéis">Senhor dos Anéis
)
Podemos também criar um label para isso (label for="Filmes">/label)
