Checkbox, Radio

Aqui veremos os inputs de "checkbox" e "radio" que servem para preechimento de questionário e formularios.
Também temos a presença do "label" (rótulo), que serve para ligar um elemento ao outro. Como por exemplo usamos o "label" para ligar o texto "c#" ou "javascript"
a caixa na sua frente através de um atributo "for" e "id" dentro de cada um, assim:

(label for="c#">C# /label),
(input id="c#" type="checkbox" name="linguagens").

Um atributo que pode ser colocado aqui é o "checked" que serve para marcar o checkbox sempre que a pagina for atualizada, mas acho que isso não é necessário já que quem vai marcar as coisas é o usuário.

Uma coisa importe para os dois grupos de inputs é que o atributo "name" precisa ser igual para cada um seja o checkbox ou radio.
No primeiro exemplo 'linguagens' o name para o C# e Javascript são os mesmos (name="linguagens") da mesma forma que o 'name' para o gênero são os mesmo (name="genero").
No segundo, gênero, é muito importante que seja o mesmo nome já que e o 'input radio' posso marcar apenas um diferente do checkbox que pode marcar vários.
