Formulário

Os formulários tem dois tipos de envios diferentes o GET e o POST.

Formulário com GET

Primeiro veremos o GET e para escrever isso faremos assim:
(< form method="GET" action="index.html">
< input type="text" name="q" value="">
< input type="submit" value="Enviar">
)
O atributo "action" vai dizer para nosso formulário para onde queremos enviar os dados preenchidos.
Normalmente esse atributo joga os dados para um back-end para tratamento deles e salvamento ou alguma outra sessão.

O GET vai passar as informações que a gente colocar por parametro na URL igual o Google faz, por exemplo.
Na URL do google (ttps://www.google.com/search? q=netflix&sca_esv=f1fd60fc7b0159d6&sca_upv=)
Esse "q=netflix" é o GET que o Google pega como parametro quando fazemos alguma pesquisa.

Formulário com Post

Agora veremos o POST: o post normalmente é mais utilizado para quando queremos fazer algo mais seguro
como por exemplo fazer um login, onde o usuário vai colocar sua senha.

Para escrever isso faremos assim:
(< form method="POST" action="index.html">
< input type="text" name="q">
< input type="submit" value="Enviar">
)

Podemos trocar o "index.html" para um "index.php" que receberia esses dados de forma muito mais segura,
salvaria em um bando de dados e também faria a verificação se aquele usuário está cadastrado no sistema e permitir esse login.

Aqui no final colocamos um extra que é o (< input type="file">) que serve para enviar arquivos do nosso computador para o servido de cadastro.
No nosso caso Facebook Test.
Mas para que isso funcione devemos colocar o atributo (enctype="multipart/form-data") no nosso forumlário, assim:
(< form method="GET" action="index.html" enctype="multipart/form-data"> < /form>)
O "enc" é o nome para 'encode' que é como esses dados serão tratados quando forem enviados para o servidor back-end.
E o ("multipart/form-data") é para informar que nosso arquivo é uma imagem. Se não colocaramos isso então nosso botão de 'file'
não vai servir para nada porque não vai funcionar.

Outro atributo que podemos colocar em nosso formulário, em cada campo de preenchimento, é o "required".
Esse atributo é para informar que alguns campos são obrigatórios, caso o usuário tente enviar sem preencher algum campo
vai da erro e o usuário precisa voltar para preencher tudo ou apenas o que é necessário.
