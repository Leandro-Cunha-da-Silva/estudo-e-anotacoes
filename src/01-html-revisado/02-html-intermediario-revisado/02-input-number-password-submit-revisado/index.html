Inputs Number, Password, Submit

Aqui vamos criar mais alguns 'inputs' e no primieor exemplo vamos fazer o (input type="number"). Nesse input vamos colocar apenas números.
O próximo input é o password que é referente a senhas. Nesse input o texto e/ou número que colocamos só mostra bolinhas ou asteristicos. Afinal de contas esse input é de senha e ninguém pode ver sua senha.
O útimo input dessa aula é o (input type="submit") que serve para enviar seu formulário. Para que esse input funcione ele precisa esta dentro da tag de (form - formulário). Para ver a tag "form" clique aqui.
