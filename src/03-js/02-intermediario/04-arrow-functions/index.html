Arrow Functions:

Também são funções anônimas, elas não terão um nome epecífico. Essas são funcções terão a escrita reduzida e podemos fazer assim:

Usaremos o código da aula anterior como exemplo.

                let resultadoDaSoma = function(numero1, numero2){
                    return numero1 + numero2
                }

                console.log(resultadoDaSoma(12, 5));

Simplificando isso com arrow fica assim:

Aqui tiramos a 'function' e colocamos a ' => ' antre os parênteses e as chaves.

                let resultadoDaSoma = (numero1, numero2) => {
                    return numero1 + numero2
                }

                console.log(resultadoDaSoma(12, 5));

Se a função não receber parâmetros, que no caso são, "(numero1, numero2)", podemos simplificar mais ainda. Aqui vamos usar o seguinte código com apenas um parâmetro:

Caso queira colocar os parênteses em '(nomeQuester)' não tem problema, vai funcionar da mesma forma, porém quanto menos coisa escrever melhor e ainda tendo apenas 1 parâmetro não tem necessidade de parênteses.

                const incentivarQuester = nomeQuester => {
                    console.log('Parabens ' + nomeQuester + ', você chegou ao JS Inter.');
                    
                }

                incentivarQuester('Leandro')

E da para simplificar ainda mais, se o código tiver apenas uma linha na sua na usa execução para para retirar as chaves '{}' e o 'return'.

                let resultadoDaSoma = (numero1, numero2) => numero1 + numero2

                console.log(resultadoDaSoma(12, 5));
