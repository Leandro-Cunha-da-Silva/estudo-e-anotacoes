Console e comentários no JS

O console é um objeto que nos fornece acesso ao console de debug do navegador. Se escrevermos "console.log("Olá mundo!")" e abrir o navegado apertar F12 e ir na aba de console vamos ver esse comando impresso lá. O '.log' é uma função do console.

Link de apoio para o console.


Para fazer comentários no JS podemos fazer linha a linha colocando '//' ou selecionar o que queremos e apertar 'CTRL + :' ou ainda colocando '/* */' em todo o código que queremos comentar. Simples.

No inicio dos estudo tudo bem colocar comentáris para fins didaticos mas no trabalho é bom que não tenha nenhum comentário.
