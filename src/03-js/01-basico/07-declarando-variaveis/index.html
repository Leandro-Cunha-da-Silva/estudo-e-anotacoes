Declarando Variáveis

As variáveis ocupam espaço no computador, nesse sentido todo o software que a gente desenvolve vai está ligado ao hardware que hospeta esse site ou sistema. Então quanto mais variáveis nosso sistema tiver mais espaço ele precisar ocupar.

É importante entender isso para não sair escrevendo código de qualquer jeito se não nosso sistema vai precisar de muito espaço e não vai ter hardware que aguente isso tudo, fora que isso eleva os gastos de armazenamento, haja dinheiro para tudo isso.

As variáveis servem para a gente armazenar valores e pode usar-los em todo o nosso código. Para usar uma variável prcisamos declarar ela no JS que são:

  • Let
  • Const
  • Var

Para usar uma variável não podemos declarar alguns nomes como 'function' e não podemos colocar espaçoes entre os nomes, ex.: 'var nome do cliente'. Esse "nome do cliente" não é aceito o correto é que seja escrito assim: nomeDoCliente, dessa fomra chamada de camel case.

No exemplo: 'var nomePessoa = "Leandro";' aquele sinal de '=' não é para comparar e sim atribuir valor a nossa variável e o valor dela é o nome "Leandro".

Diferenças entre variáveis: const e var. O que difere elas é que ao usar o const não podemos mudar o valor dela, ela se torna uma variável constante. já a var permite isso e ela vai renderizar o último valor atribuído a ela.

A variável let podemos atribuir outros valores a ela e ela também vai imprimir o último valor posto nela.

A diferença entre let e var está no escopo que é aonde aquela variável vai existir. No caso são variáveis de escopo global, função(local) e de bloco.

  • Escopo Global - que são variáveis que podemos usar em qualquer lugar do nosso código.
  • Escopo de Função - que são variáveis que vamos usar apenas dentro de uma função.
  • Escopo de bloco - que são variáveis dentro de chaves ou de if, else, ou dentro de loops (laços de repetição).

O escopo de bloco não é suportado pelo var. Para fazer escopo de bloco bastar colocar seu código dentro das chaves '{}'

O let e o const só funcionam no escopo local(função).
