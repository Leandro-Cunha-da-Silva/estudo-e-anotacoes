Condicionais Parte 1

Condicionais são basicamente um funil de escolhas e eles vão determinar se o código será direcionado por um determinado fluxo ou outro, baseado em uma expressão de lógica.

Primeira condicional: if (se) - Se o valor da expressão for verdadeiro, o bloco de código dentro do if será executado.

Outra condicional: else (senão) - Se o valor da expressão for falso, o bloco de código dentro do else será executado.
