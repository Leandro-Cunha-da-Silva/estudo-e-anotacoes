O que são tipos primitivos no JS?

Os tipos primitivos são os tipos de variáveis que vamos ter no JS e eles são a estrutura fundamental do nosso código.

O JavaScript tem 6 tipos primitivos que são:

  • String - esse usa um tipo texto que pode ser feito com aspas duplas ou simples.
  • Number - esse usa um tipo estilo número, para ele não precisa de aspas é só escrever o números. Pode usar número inteiros ou decimais positivos ou negativos.
  • Boolean - esse é o tipo boleano que serve para indicar algo verdadeiro(true) ou falso(false). Também não precisa de aspas.
  • Null - esse tipo normalmente vai apontar para um endereço de memória inválido ou inexistente. Também não precisa de aspas.
  • Undefined - esse é quando o js não consegue definir um tipo para a variável. Esse é o prório JS quem define, não precisamos escrever nada, aqui só esta sendo posto(escrito) para exemplo de aula.
  • Symbol - esse é pouco usado, por enquanto vai ficar de lado. No futuro faço atualizações.
