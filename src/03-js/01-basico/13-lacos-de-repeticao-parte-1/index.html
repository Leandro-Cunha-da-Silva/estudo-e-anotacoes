Laços de repetição (loops) parte 1 (FOR)

Anatomia do 'For': "for(inicializador; condição; incremento){ declaração}"

Inicializador: vai ser utilizado para iniciar um contador de variáveis. Podemos usar um 'let' dentro do for por exemplo ou fora e interar com o for para inicializar.
Condição: aqui terá uma expressão que vai ser avaliada a cada uma das interações do loop, e se o resultado dessa expressão final for 'true' a declaração, que é o que vem dentro do for, vai ser executada.
Incremento: aqui vamos incrementar a variável, a cada intereção vamos incrementar com +1 para ele fique executando e incrementando a variável até chegar numa condição predefinida no segundo paramentro.
Declaração: que vai ser o bloco de código que vai rodar todas as vezes que o for executar.
