GAP

O GAP é uma propriedade do CSS que serve para definir o espaçamento entre todos os itens de um container, seja ele flex ou grid.

O GAP também é um shorthand para 'column-gap'(gap em coluna) e 'row-gap'(gap em linha). Isso significa que podemos escrever ele com dois valores, o primeiro valor se refere a 'column-gap', ele só vai ser aplicado quando o flex-direction for definido como 'column', e o segundo valor refere-se a 'row-gap' que só vai ser aplicado quando o flex-direction estiver defindo como 'row'.

Podemos utilizar valores em pixels ou porcentagem.

Importante! O GAP só espaça os elementos filhos do container flex ou grid, ele não cria espaçamento ao redor dos itens como o margin faz. Então ele só cria um espaço entre os itens dentro do container.
