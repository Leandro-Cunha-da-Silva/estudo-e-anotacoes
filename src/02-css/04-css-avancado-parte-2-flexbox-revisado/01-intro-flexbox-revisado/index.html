O que é, para que serve e o que ele resolve? Flexbox.

O Flexbox permite criar uma estrutura de layut mais flexível e adaptável, facilitando o alinhamento e a distribuição dos elementos dentro de um contêiner, dispondo, alinhando e distribuindo o espaço entre eles de fomra eficiente.

o Flexbox é mais indicado para layouts de pequena escala e componentes de um site. Também é muito bom para centralizar e posicionar elementos.

O Flexbox trabalha com conceito de pai e filho, onde o pai é chamado de 'flex container' e o filho de 'flex itens'.

O Flexbox é uma ferramenta poderosa para criar layouts responsivos e adaptáveis, facilitando o desenvolvimento web moderno.

O flex trabalha com conceito de eixos que são o eixo principal e transversal. O comportamento desses dois eixos são definidos pela propriedade css 'flex-direction', é ela quem vai ditar as regras dos eixos. O flex-direction possui quatro valores principais (row, row-reverse, column e column-reverse).
