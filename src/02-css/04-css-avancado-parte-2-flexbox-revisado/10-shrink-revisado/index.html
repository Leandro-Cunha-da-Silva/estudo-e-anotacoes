Flex shrink

O shrink serve para encolher, ele vai definir a capacidade de um item encolher ou não de tamanho, caso seja necessário, dentro do container flex. O valor padrão de shrink é 1.

Quanto maior o valor do shrink maior será a capacipadade dele de encolher, 1, 2, 3...
