Align items

Da para pensar no Align-items como se fosse o justify-content, mas para alinhar os itens no eixo transversal.

Align-items: flex-start

O Align-items se move ao longo do eixo transversal. Ele vai alinhar os itens do inicio para a vertical, nesse caso isso acontece porque o flex-direction está definido como row, valor padrão.

Align-items: stretch (esticar)

Para o stretch funcionar assim ele precisa que não tenha nenhuma altura fixa, então ele vai esticar até ocupar a altura máxima dentro do container. Nesse caso o flex-direction está definido como row, então o eixo transversal está na vertical, ou seja, aumentar a altura deles.

Se definir o flex-direction como column o stretch vai esticar os itens na horizontal, aumentando a largura deles.

Align-items: baseline

O baseline (linha de base), ajusta/alinha os itens de acordo com a linha de base do conteúdo.

Imagine escrever nas linhas do caderno, escrevemos as letras e números em cima das linhas, mas se escrever alguma letra ou número maior ele apenas cresce para cima, mas a linha de base continua a mesma, não escreveos abaixo da linha e sim continuamos escrevendo em cima independente do tamanho da letra.
