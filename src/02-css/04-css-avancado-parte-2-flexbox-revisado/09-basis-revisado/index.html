Basis

O flex-basis vai permitir que os itens de um container flex tenham sempre o mesmo tamanho, independente do conteúdo dentro deles. Então, mesmo que o conteúdo seja maior ele vai respeitar o valor que a gente colocar no flex-basis.

Podemos definir valores em pixels, porcentagem ou auto. Deixar como 'auto' já é o padrão do flex-basis.
