GROW

Essa propriedade vai definir a capacidade de um elemento aumentar de tamanho e ocupar mais espaço dentro do flexbox container. O Grow possui valores inteiros que vão de 0 a 3, quando maior o valor, maior a prioridade e quanto menor, menor a prioridade. Assim como no flex container precisamos aplicar 'display flex' para que o grow funcione.

O valor padrão do Grow é 0, ou seja, o item não vai crescer além do seu tamanho original. Se todos os itens tiverem o valor 1, eles vão crescer igualmente. Se um item tiver o valor 2 e outro o valor 1, o item com valor 2 vai crescer o dobro do tamanho do item com valor 1.
