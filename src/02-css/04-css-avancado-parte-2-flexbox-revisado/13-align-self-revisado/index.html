Align-self

A propriedade align-self vai alinhar um único elemento ao longo do eixo transversal. Essa é uma propriedade de flex item, então vamos aplicar diretamente no elemento filho e com isso vamos poder mover um único elemento ou mais se quiser.

O valor padrão do align-self é o 'auto'.
