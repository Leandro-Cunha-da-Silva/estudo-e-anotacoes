Flex-wrap e Flex-flow

Flex-wrap é um propriedade de flex container.

Flex-wrap, define se os itens devem quebrar ou não a linha. Por padrão os itens não quebram linha

O Flex-wrap move os itens ao longo do eixo transversal, seja na horizontal ou vertical, dependendo da direção do flex-direction. Mas se não tiver mais espaço disponivel dentro do container ele quebra os itens ao lingo do eixo transversal.

Flex-flow

O Flex-flow é uma abreviação para as duas propriedades: flex-direction e flex-wrap.

Com o Flex-flow conseguimos escrever os valores em conjunto em uma única propriedade.

Ex.: ao invés de escrever "flex-wrap: wrap; flex-direction: column;" pode escrever "flex-flow: wrap column".

Lembrando que o primeiro parametro a ser definido é para o flex-direction e o segundo é para o flex-wrap.
