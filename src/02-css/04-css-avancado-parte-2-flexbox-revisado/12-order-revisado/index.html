Order

O order vai definir a ordem dos nossos flex items. Por padrão o sistema ler os itens de cima para baixo, mas agora com o order podemos modificar isso dentro do container.

O valor padrão do order é 0.

O order não tem valor fixo pré definido se quiser, por acaso, por um valor 10 pode fazer. Se um elemento possuir um valor maior, então ele ficará mais para a direita, se possuir um valor menor ficará a esquerda.
