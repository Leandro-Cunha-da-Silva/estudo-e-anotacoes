Align-content

A propriedade align-content é um mistura de align-items e justify-content, por isso esse nome.

O align-content alinha as linhas do container em relação ao eixo vertical, mas muito importante, essa propriedade só funciona se existir mais de uma linha de flex-items. Para isso o flex-wrap precisa ser wrap.

Além disso, o efeito dela apenas vai ser visualizado caso o container seja maior que a soma das linhas dos items. Isso significa que se não for definido uma altura para o container, essa propriedade não vai influênciar no layout.

Align-content: flex-start

Se mudar o flex-direction para column o eixo passará a ser horizontal, faendo com que os itens do container sejam alinhados ao inicio da horizontal.
