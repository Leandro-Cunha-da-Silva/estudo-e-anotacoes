07-Espaçamento Externo com Margin

Aqui usaremos a propriedade de espaçamento Margin para definir valores nas partes de cima e baixo, direita e esquerda.
Temos duas formas de fazer isso, na versão encurtada "shorthand", escrevendo cada valor separado, lembrando que a
segunda forma não é recomendada pois fica muita coisa na tela e coisa repetida não é legal.
Na forma "shorthand" (escrita encurtada) para colocar espaços em cima, baixo, direita e esquerda faremos assim:
"margin: 30px 15px;"

A segunda forma usando os mesmos valores, mas repetindo eles fica assim:
"margin: 30px 15px 30px 15px"

Aqui fica a mesma coisa mas repetindo a escrita não fica bom como podemos ver no exemplo.
