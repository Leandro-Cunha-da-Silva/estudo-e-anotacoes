Explicação e exemplos:

18-Box-sizing: border-box

O "box-sizing" vai nos permitir trabalhar com altura e largura de uma forma que fica mais fácil de calcular.


Também nessa aula vemos o estilo de reset mais utilizado em alguns sites:

"*,
*:after,
*:before {
margin: 0;
padding: 0;
box-sizing: border-box;
text-decoration: none;
}

body {
font-size: 100%;
list-style-type: none;
} "


- Se a gente não especificar o "box-sizing: border-box;" a largura e altura do elemento vai ser definida somando o padding e border. Então isso vai ser assim:

largura + padding esquerda + padding direita + border esquerda + border direita = largura total do elemento.
100 + 10 + 10 + 10 + 10 = 140

- Isso também é mesma coisa para altura:

altura + padding cima + padding baixo + border cima + border baixo = altura total do elemento.
100 + 10 + 10 + 10 + 10 = 140
