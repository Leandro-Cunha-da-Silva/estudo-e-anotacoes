15-Unidades de Medidas Relativas

Explicação e exemplos

Primeiro temos que entender o conceito de "pai" e "filha". O HTML e CSS respeitam uma hierarquia para organizar os elementos e isso é essencial para o CSS estilizar tudo.
Por exemplo:


Se escrever:

"body
'h1 - Pais e filhas - h1'
'div class: "pai"
PAI
'div class: "filha"'
FILHA
body"

E colocarmos a seguinte estilização:

"html {
background-color: #ccc;
font-size: 32px;
}

body {
background-color: blueviolet;
width: 50%;
}

.pai {
background-color: #ea80fc;
width: 50%;
}

.filha {
background-color: #1de9b6;
width: 50%;
}"

Ficará assim no final:

Pai
Filha

A parte cinza é o html e o body (aqui tive que fazer assim porque o código pegava na página toda e não era isso que queria. Ainda não sei isolar as coisas, paciência. rss)
Então, html e body são pai e filha respectivamente. html engloba tudo, body está dentro do html.
Dentro disso tudo temos as tags com nomes "pai" e "filha". Cada uma pegando sua parte na tela de acordo com a estilização.

Após aprender isso pordemos passar para a parte titulo desse estudo.

Medida reletiva como o próprio nome diz não é algo absoluto e sim uma medida que vai se adequar ao que está sendo apresentado na tela.
Devemos lembrar que 1em é igual a 16 pixels (1em = 16px). Cada "1em" adicionado multiplica por 16 (3em x 16 = 48px).
O "em" sempre vai olhar a propriedade do pai para setar a filha. Por exemplo:
A pagina web sempre vem por padrão com 16px (1em) e para aumentar isso precisamos setar onde queremos fazer a alterção que vai aplicar a ação relativa a tag "pai" de cada elemento.
