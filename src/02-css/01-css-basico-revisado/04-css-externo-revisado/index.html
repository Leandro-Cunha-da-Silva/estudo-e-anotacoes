04-CSS Externo

Explicação:

-Aqui uso a tag "a" de novo para escrever a Explicação.
Usando o CSS externo a gente separa cada parte com suas próprias responsabilidades.
Na parte de HTML só teremos marcação e na parte de CSS teremos todas as estilizações, assim fica melhor organizado e mais fácil de ler e fazer manutenção quando necessário.
Para cada "index.html" que for criado o CSS estiliza igual desde que todos estejam ligados ao mesmo CSS através do "link rel="stylesheet" href="./src/css/style.css"
Caso queira, para cada página, uma estilização diferente então deve-se criar um CSS para cada uma e estilizar como desejar.
