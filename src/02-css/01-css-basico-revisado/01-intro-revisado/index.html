01-INTRO: O que é CSS?

CSS significa - cascading style sheet, ou folhas de estilo em cascasta.

Qual a utilidade disso?

Serve para deixar nossa página Web mais bonita. Igual a foto a baixo 😁
Além disso o CSS serve para aplicar animações e cores para nosso projeto.
