02-CSS inline

CSS inline é a estilização que se usa dentro do próprio HTML em cada elemento de forma individual o que não é recomendado,
já que leva mais tempo para fazer e o código fica repetido e isso não é bom porque fica muita informação repetida na tela. O melhor
é fazer isso com o CSS separado como veremos na próxima aula: CSS interno: Clique aqui!

Veja o exemplo

Exemplo 1

Para fazer uma estilização inline em uma tag HTML a gente precisa colocar o atributo/propriedade/valor "style=propriedade: valor;".
Em uma tag h2 (Subtítulo) com fundo colorido por exemplo: "h2 style="background-color: blue;"

Para trocar a cor das letras de um "p" (paragrafo) fazemos assim:
"p style="color: blueviolet;"

Exemplo 2

Usando o mesmo modelo do exemplo anterior, digamos que agora queremos usar outras cores no título e parágrafo seguinte.
Vamos escrever nosso título e parágrafo e colocar cores diferentes.
"h2 style="background-color: orange;"
"p style="color: red;"

Conclusão

Fazer desse jeito deixa nosso código repetitivo e se por acaso quisermos trocar essas cores de fundo e texto futuramente teremos que fazer um por um e isso é claro não é bom já que tomaria bastante tempo e nosso código fica todo bagunçado.
Faremos esse tipo de estilização em último caso se for extremamente preciso.
