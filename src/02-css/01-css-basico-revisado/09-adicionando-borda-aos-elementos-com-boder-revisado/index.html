09-Adicionando borda aos elementos com border

Elemento "border" como o próprio nome já diz adiciona borda em volta dos elementos.
Primeiro devemos colocar "border:" e dizer para esse elemento que tipo de borda queremos por exemplo:
"border: solid 10px;"

Temos vários tipos de borda, mas o que mais utilizaremos na real é o "border: solid;" do exemplo aceima.
