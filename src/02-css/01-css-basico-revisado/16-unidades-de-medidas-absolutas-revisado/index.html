16 - Unidade de medidas absolutas

Explicação e exemplos

Usar uma unidade de medida absoluta para difinir altura e largura de um elementos é algo que pode trazer alguns problemas quanto a responsividade. Esse tema de responsividade veremos mais para frente no curso.
O que não podemos fazer é colocar algo muito grande em uma tela que não é permitido isso como exemplo fazer um site com medidas grandes para abrir em um celular. As dimensões do dispositivo móvel são diferentes e não pode haver rolagem lateral (é bom que nem tenha rolagem quando aberto no pc também). Por isso usar medidas absolutas pode gerar problemas quanto a responsividade se usar isso de forma grande demais.
Veremos como resolver isso quando chegarmos na parte de responsividade do curso. Intermediário - aula 13
