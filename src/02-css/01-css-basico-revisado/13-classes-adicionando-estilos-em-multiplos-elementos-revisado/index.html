13-Classes: adicionando estilos em multiplos elementos

Explicação e exemplos

Aqui usaremos as classes para estilização. Podemos utilizar várias classes com nomes iguais sem problemas só pense em nomes bons para elas para que no futuro ou quando for fazer manutenção se localize com facilidade. Quando for chamar as classes no CSS devemos colocar:
".nome da classe {
}"

Dentro das chaves colocamos os estilos desejados.
