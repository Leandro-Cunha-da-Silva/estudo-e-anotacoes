12-IDs ou identificadores e Classes

Explicação e exemplos

Não podemos colocar dois IDs com o mesmo nome na mesma pagina web. Se colocar vai funcionar, mas é considerado errado para W3C. Em caso de colocar dois IDs com a mesma descrição e fizer a chamada deles no CSS eles funcionaram da mesma forma mesmo sendo para coisas diferentes.

Para chamar o ID no CSS precisamos colocar a "#" na frente e depois sua descrição: "#descrição-ps5"
