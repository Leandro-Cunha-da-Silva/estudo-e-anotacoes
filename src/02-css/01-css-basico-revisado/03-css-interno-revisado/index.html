03-CSS Interno

Explicação

-Aqui usei a tag "a" para escrever a explicação porque a tag "p" quando colocado no head modificava tudo. Rss


Para estilizar usando o CSS interno devemos começar abrindo a tag "style" no "head" da nossa estrutura base HTML. Isso é importante! "style" tem que vim dentro do "head"!
Dentro dessa tag precisamos sinalizar o que vamos estilizar, como exemplo:
Queremos estilizar os "h2" dentro do "style" colocaremos:
"h2 {
background-color: aquamarine
}"

E para fazer isso com o a tag "p" faremos o mesmo:
"p {
color: blueviolet
font-size: 24px
}"
