14-Div e Span

Explicação e exemplos: DIV

Primeiro exemplo veremos o uso das "div". Uma "div" não possui peso semântico, ela básicamente não faz nada na tela, usamos a div para dividir coisas e agrupar tudo. Varemos isso no exemplo a seguir:

Digamos que faremos o anúncio de um produto nesse caso teremos o título "nome do produto" e a descrição dele:
Playstation 5
Um baita videogame
R$ 5000,00

Nesse exemplo queremos que o fundo do produto e sua descrição seja toda em azul. Para isso usaremos uma "div" com uma classe para estilizar tudo isso:
"div - class:"produto"
h2 - Playstation 5
p - Um baita videogame
p - R$ 5000,00"

Essa é nossa forma de escrever no HTML e para chamar isso no CSS usaremos:
".produto {
background-color: azul
}"

O resultado disso fica assim:

Playstation

Um baita videogame

R$ 5000,00

Explicação e exemplo: SPAN

O span é um elemento do tipo "inline lvl" e nele podemos englobar algo e estilizar somente um pedaço de texto. Ainda podemos colocar no span uma classe se preferir. No exemplo a seguir usaremos somente span sem classe:


"Um baita 'span' videogame! 'span'
R$ 5000,00"

A palavra 'videogame!' posta entre o "span" que será modificada e agora queremos ela maior e para tanto vamos chama-lá no CSS assim:
".explicacao-exemplos-span span {
font-size: 24px;
color: orange;
}"


Um baita videogame!

R$ 5000,00
