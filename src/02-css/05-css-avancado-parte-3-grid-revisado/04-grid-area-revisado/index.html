Grid Area

O grid area é uma abreviação do grid column e grid row. Aqui temos os valores grid-row-start, grid-column-start, grid-row-end e grid-column-end, nessa ordem.

Código:

.verde-claro { grid-area: 1 / 1 / 3 / 3; }
.azul { grid-area: 1 / 3 / 1 / 6; }
.rosa { grid-area: 3 / 1 / 3 / 3; }
.laranja-escuro { grid-area: 2 / 3 / 4 / 5; }
