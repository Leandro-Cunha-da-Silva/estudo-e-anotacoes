Grid - ocupando espaços

Para fazer com que nossos elementos ocupem espaços no grid, como visto na foto de exemplo da aula 01 - Grid o que é?precisamos entender como fazer isso.

.container-exemplo { display: grid; grid-template-columns: repeat(5, auto); grid-template-rows: repeat(3, auto); grid-gap: 15px; }
.verde-claro { grid-column: 1 / span 2; grid-row: 1 / span 2; }
.span { grid-column: 1 / span 2; }
