Propriedades do Grid

Grid-template: repeat

A primeira que vamos falar é a 'repeat'. Imagina que temos muitas linhas no nosso grid e para isso vamos ter que colocar, para cada linha, seus respectivos tamanhos e isso é muito trabalho. Então para isso serve o repeat.

Para usar o repeat escrevemos assim: grid-template-rows: repeat(3, 150px);

Isso serve tanto para linhas, quanto para colunas: grid-template-columns: repeat(2, auto);

Podemos também abreviar esses valores em uma única linha de código, o que é bem melhor. Então ficaria assim: grid-template: repeat(3, 150px) / repeat(2, auto);

Note que o primeiro valor é a linha e depois as colunas. Precisa ser assim.

Grid-gap:

O Grid-gap vai ser o tamanho entre as colunas e as linhas.

Então se aplicarmos uma grid-gap: 10px; ele da um espaço de 10px entre todas as colunas e linhas.

Se quiser definir só um espaço entre colunas pode basta escrever: grid-column-gap: 10px;

E para por espaço somente entre as linhas: grid-row-gap: 10px;

Também podemos escrever de forma abreviada, que como sempre é melhor. Para isso vamos usar o grid-gap que vimos antes, agora com dois valores vamos colocar primeiro a linha e depois as colunas, assim: grid-gap: 10px 20px;

grid-min-max:

Essa propriedade é bem interessante, pois ela faz com que a gente defina um tamanho mínimo e máximo para as colunas ou linhas. Assim, se o container for maior que o tamanho máximo, ele não vai ultrapassar esse valor. E se for menor que o tamanho mínimo, ele não vai diminuir mais que esse valor.
