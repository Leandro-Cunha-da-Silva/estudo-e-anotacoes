Grid template area

Para usar o grid area basta escrever os nomes das areas que queremos que ocupem determinados espaços na tela, seguindo uma ordem como no código abaixo. O container é aonde tudo vai ser posto e as divisões abaixo são as areas que queremos agrupar no container.


Código:

.container-exemplo {
display: grid;
grid-template-areas: "cabecalho cabecalho cabecalho"
"menu-exemplo secao-principal aside"
"rodape rodape rodape";
}

.cabecalho { grid-area: cabecalho; }
.menu-exemplo { grid-area: menu-exemplo; }
.secao-principal { grid-area: secao-principal; }
.aside { grid-area: aside; }
.rodape { grid-area: rodape; }
