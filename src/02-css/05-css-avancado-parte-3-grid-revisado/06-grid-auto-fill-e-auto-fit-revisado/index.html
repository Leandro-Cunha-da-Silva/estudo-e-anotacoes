Grid auto-fill e auto-fit

Usando o auto fill ou auto fit conseguimos deixar nossa página responsiva sem usar Media Queries.

A diferença entre elas são: o auto-fill trava nossa página de acordo com o valor que colocamos, como no exemplo, 200px. Se ainda tiver espaço sobrando ele cria espaços vazios, colunas invisiveis.

Auto-fill: grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));


Já o auto-fit vai estender as colunas para preencher todo o espaço da tela ou container.

Auto-fit: grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
