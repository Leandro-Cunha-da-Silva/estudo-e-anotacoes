Transform

Com o transform a gente pode aplicar transformações nos elementos HTML. Vejamos algumas:



Transform Scale

No scale a gente muda a escala dos elementos (comprimento e largura) as medidas são menores já que os valores são calculados em 2x. Exemplo: 2, 3. São 2 vezes e 3 vezes, respectivamente.

Também podemos usar esse comando como ScaleY (vertical) ou ScaleX (horizontal) e aqui usamos apenas um parametro de medida e não dois como no exemplo anterior.

"img.scale {transform: scale(2, 3);}"
















Transform Rotate

Outros usos do transform como o Rotate. Com essa função a gente rotaciona o elemento. Aqui colocamos as medidas em "graus" como no exemplo 45deg (45graus)

"img.rotate {transform: rotate(45deg);}"







Transform Translate

Outros usos do transform como o Translate. Com essa função a gente move o elemento. Aqui usamos as medidas em pixels.

"img.translate {transform: translate(50px, 20px);}"
