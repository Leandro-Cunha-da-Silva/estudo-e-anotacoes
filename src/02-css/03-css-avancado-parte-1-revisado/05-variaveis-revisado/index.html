Variaveis

Nas variáveis temos que tomar cuidado com a compatibilidade com os navegadores (browsers)

As variáveis podem ter o escopo global ou local. A variável global pode ser utilizada em todo o documento e todos os estilos. E a variável local só vai pode ser utilizada no seletor que ela foi criada.

Global

Aqui queremos colocar uma cor para todos os textos, para isso usamos a variável ":root", que é a raiz do documento, podemos definir uma estilização para tudo aqui dentro. Para escrever uma variável escrevemos "--" antes de escrever o nome da variável "--cor-padrao: green;", "--tamanho-de-fonte-padrao: 20px;".

":root {--cor-padrao: green; --tamanho-de-fonte-padrao: 20px;}"

Para definir a variável nos itens do documento, primeiro colocamos o que vamos estilizar, seguido de var(*nome da variável padrão*).

Para a variável de cor do texto usamos: "color: var(--cor-padrao, blue);" esse 'blue' é para dizer que, caso de algum problema na variável pode utilizar outra, 'blue'.

Para a variável de tamanho da fonte usamos: "font-size: var(--tamanho-de-fonte-padrao, 20px);"

Vantagens de usar variável global é que fica mais fácil de ler e alterar o código caso seja necessário.

Local

Para utilizar uma variável local, que só vai ser utilizada em um elemento, fazemos assim:

Dentro do elemento que queremos usamos: "h2 {--cor-padrao: yellow; color: var(--cor-padrao, blue); background-color: var(--cor-padrao);}

Note que não precisa mais do ":root" que é a raiz. Como aqui é o local não precisa de "root.
