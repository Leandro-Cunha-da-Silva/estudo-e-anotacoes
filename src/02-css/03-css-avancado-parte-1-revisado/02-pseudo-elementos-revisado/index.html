Usando Before:

Before vai inserir um conteúdo antes do elemento que estamos estilizando.

Por exemplo, se queremos colocar um determinada imagem antes de cada H2 na nossa página, temos a opção de por ela repditas vezes no HTML, o que é rui já que vai carregar a mesma imagem na frente de cada H2. Agora, usando o 'before' no CSS usamos uma única imgem que vai aparecer na frente de cada H2 como desejado sem pesar a nossa página.
