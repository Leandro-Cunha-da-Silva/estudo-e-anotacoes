Pseudo Classes

Pseudo classes são palavras que colocamos depois de um seletor separados por dois pontos ':'. Elas servem para estilizar estados dos seletores, outros elementos da página ou também fatores externos como por exemplo o histórico de navegação, usando o 'visited' que serve para estilizar um link que já foi visitado pelo usuário. Como visto em aulas anteriores aqui.

Dentro dessa pseudo classe podemos passar alguns argumentos que já são definidos, como por exemplo o "odd" que vão ser todos os elementos ímpares desses irmãos.

Only Child

Essa pseudo Classe estiliza um elemento que não tenha elementos irmãos. Exemplo se tenho duas div, mas uma delas tem apenas 1 filho e na outra tem dois filhos, essa pseudo classe vai estilizar apenas a primeira div porque ela tem apenas um filho.
