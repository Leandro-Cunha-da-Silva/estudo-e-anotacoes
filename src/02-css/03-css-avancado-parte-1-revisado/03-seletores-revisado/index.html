Seletores

*Estilização com Seletor*

Existem várias formas de estilizar um seletor, uma delas é puxando a própria tag como (h1, h2..., div, section, nav, html, etc.).

Outra meneira de fazer isso é chamando a classe, que sempre puxamos ela no CSS usando o ponto (.), seguido do nome da classe. Ex.: ".classe".

Também temos o ID que chamamos no CSS usando o "#". O ID só vem 1 vez por página, não pode ter outro ID com o mesmo nome na mesma página.




*Estilização com ID*

Outro seletor é o ID que a gente puxa usando o '#'.

O ID não é recomendado para fazer estilização, recomenda-se usar as classes 'class'. ID é bom para intereções com JS (JavaScript).

Asteristico (*)

O (*) para estilizar é mais usado em Resests para modificar a página toda. Colocando isso no arquivo CSS faz com que todos os elementos da página tenham as mesmas especificações.

Ex.: se colocar um "* {padding: 0; font-size: 20px;}" isso vai deixar toda minha pagina com esses valores.


*Estilização com duas classes*

Podemos utilizar duas classes no mesmo elemento. A primeira classe será a base para caso queira que todas elas tenham o mesmo estilo como por exemplo mesmo tamanho de fonte. Então, como todas tem a classe "titulo" (h3 class="titulo vermelho") basta escrever o código com esse elemento e colocar o "font-size:" e o tamanho desejado.

Para colocar as duas classes escrevemos ".ELEMENTO1.ELEMENTO2", veja que não colocamos espaços entre os dois pontos é tudo junto mesmo.

*Estilização com Vírgula*

Podemos também utilizar a estilização separadas por vírgula, assim todos os elementos separados por vírgula terão a mesma estilização.

"p, span {font-size: 20px;}"

*Estilização com classe filha*

Para estilizar uma classe filha, a gente precisa separar os pontos com espaço. Ex.: ".classe1 .classe2".

".sobre .texto {color: palevioletred;}"

*Estilização com seletor sinal de maior '>' *

Estilizando com sinal de maior '>' a gente consegue nexer em todos os elementos filhos.

"div > p {color: royalblue;}"


*Estilização com seletor '+'' *

Para estilizar usando o sinal de '+' a gente precisa colocar os elementos separados. Ex.: se eu quero estilizar uma tag 'p', ela não pode ser filha de nenhuma outra, ela precisa está separada, fora de outra tag. Lembre da hierarquia (tags pais e filhas).

Usando esse tipo de estilização com o sinal de '+' eu consigo estilizar a primeira tag 'p' que estiver fora de qualquer outra tag. Somente a primeira tag 'p' que estiver fora de qualquer outra tag será estilizada, se houver mais de uma tag 'p', somente a primeira será estilizada.


*Estilização com atributo*

Para estilizar dessa forma podemos chamar o "target" e precisamos escrever:"a[target=_blank] {color: red;}".
