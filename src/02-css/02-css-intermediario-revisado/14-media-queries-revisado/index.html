Anotações/Explicação

Media querie é o código que usamos para aplicar outras dimensões na nossa página. Quando a tela é grande vai ter um comportamento e quando a tela for menor ou for diminuindo terá outros valores e por isso nossa página tem que acompanhar os novos tamanhos de dela para melhor visualização do usuário.

Para escrever uma media queria fazemos assim:
"@media (max-width: 576px)"
