Backgrounds

Background image

O "background-image: url()" - serve para colocar uma imagem a partir do CSS.

Background Repeat

O "Background-repeat: no-repeat" - faz a imagem não se repetir. Assim ele não fica repetindo ao longo da página. Além disso essa propriedade faz com que a imagem fique grudada no canto superior esquerdo da tela.

Background Size cover

O "Background: cover" - faz a imagem preencher todo o espaço da que tem na tela. Só cuidado para não por uma imagem pequena para ocupar um espaço grande se não vai ficar todo feio.

Background fixed

O "Background-attachment: fixed" - serve para fixar a imagem ao fundo. Assim quando scrollar a página para cima ou para baixo a imagem fica no fundo e não acompanha esse scroll. Esse efeito também pe chamado de Parallax.

Background position

O "Background-position: "- serve para deslocar a imagem na tela conforme nossa preferência. Para fazer isso devemos colocar: "background-position: bottom right;" - aqui no position podemos colocar dois valores que são position horizontal (X) e vertical (Y). E para a imagem não se repetir colocamos "background-repeat: no-repeat;".

Podemos fazer isso de forma encurtada também, assim: "Background: #000 url(1./imagem-da-sua-escolha') no-repeat right top;".

Com apenas uma linha de código conseguimos passar todos os valores necessários para nossa imagem ficar como queremos. Sempre que possível vamos fazer assim e lembrar SEMPRE de fazer na ordem CERTA se não vai da rui e isso não vai funcionar.
