Fontes do Google Fonts

Para essa aula vamos usar o site do Google Fontes para pegar nossas fontes. Clique aqui.

Uma vez no site é bem fácil fazer a importação as diversas fontes para o nosso projeto. A melhor maneira de importa é clicar na fonte, ir em "Get font", depois em "Get embed code", após isso clicar em "@import" e depois copiar o que tem dentro do "style". Uma vez copiado é só colar no CSS e pronto! A fonte já esta em uso. Aqui usei a fonte "Fira Code" com pesso de "700".
