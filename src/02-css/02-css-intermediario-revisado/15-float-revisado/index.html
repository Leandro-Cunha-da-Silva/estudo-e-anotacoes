Explicação

O Float serve para soltar o elemento do fluxo normal da página e fazer com que ele flutue na tela seja para (left) ou (right). Float é usado para que textos englobem uma imagem.

Podemos fazer o Float flutuar tanto a esquerda quanto a direita na nossa página, ou até mesmo deixar 'none' que é o comportamento padrão.

O Float foi criado para essa função, mas não é a melhor opção e hoje em dia temos outras formas de fazer isso usando o "display: flex" e o "display: grid" que ajuda a gente a trabalhar de maneira mais fácil e correta.
