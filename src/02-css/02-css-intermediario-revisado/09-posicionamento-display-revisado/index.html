Display block

Um elemento "display block (block level)" por padrão sempre ocupa a largura da tela toda. Para controlar isso colocamos a largura que queremos que ele ocupe usando "width: 100px;" (ou o valor desejado). Esse elemento também fica um de baixo do outro, mas podemos mudar isso colocando lado a lado. Vejamos o exemplo abaixo: "display inline"

Display inline

Para deixar nossos elementos em linha(um do lado do outro) utilizamos o seguinte "display: inline;". Um ponto importante é, se colocar 'display: inline;' não vamos conseguir colocar altura (height) ou largura(width) no elemento. Não importa o que você ponha, pixel ou porcentagem nada disso funciona já que o comportamento padrão dessa propriedade é exatamente essa.

Para conseguir colocar altura e largura no nosso elementos precisamos por "display: inline-block;", vamos ver isso no exemplo a seguir.

Display inline-block

Aqui usando o "display: inline-block;" podemos colocar altura(height) e largura(width) ao nosso elemento. Ex.: "width: 100px; e height: 100px;".

Display none

Por último temos também o "display: none;" que serve para esconder o elemento da tela. Isso é usado para esconder elementos muito grande no celular(mobile) por exemplo, mas isso veremos no media queries. Para ir nessa explicação clique aqui.

Lembrando que o elemento só ficou oculto, mas ele ainda esta no nosso HTML basta inspecionar o elemento que você verá ele aí.
