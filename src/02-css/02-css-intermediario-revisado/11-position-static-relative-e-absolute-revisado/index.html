Estatic

Um elemento static sempre ficará fixo na página, mesmo que coloquemos valores para reposicionar, ele não irá funcinar nesse tipo de elemento, ele ficará travado porque esse é o comportamento padrão.

Static

Relative

Essa propriedade de elemento 'relative' vai dizer que esse elemento vai esta posicionado relativamente ao lugar que ele foi criado na nossa tela. Ele está logo abaixo do elemento Static porque o static é um "display: block;" então ele ocupa a linha toda e o único lugar que o relative pode ficar é em baixo.

Agora com esse elemento, se a gente quiser reposicionar ele, podemos fazer. Se usarmos um "left: 100px;" ele ficará um pouco para o lado direito 100 pixels. Quando usamos o left (esquerda) o elemento é empurado para a direita. Isso acontece porque estamos dizendo que queremos um espaço entre a borda esquerda e o elemento, por isso ele vai para direita.

Agora sim podemos mover o elemento para onde quisermos. Lembrando que quando usamos algum comando não estamos querendo mover o elemento e sim da um espaçamento entre o elemento e as bordas dele. Por isso ele se move ao contrario do que pedimos como o caso do "left".

Relative

Absolute

Quando colocamos um elemento com o "position: absolute;" estamos dizendo que estamos destacando esse elemento da camanda padrão/original dele.

Com o esquema de camadas, quando colocamos o "position: absolute;" estamos criando uma camada nova e qualquer elemento que esteja abaixo disso vai subir e ficar atrás do 'absolute'. Logo abaixo desse elemento temos outro elemento mas ele está atrás. se colocarmos, por exemplo um "left: 200px;" veremos o elemento que está atrás.

Absolute

Outro elemento Estatico

Absolute com pai

Existe uma maneira de deixar esse elemento no lugar onde ele foi criado. Da seguinte forma. Vamos colocar o elemento com position absolute dentro de um elemento que tenha o position relative. Criaremos uma div dentro da outra (div pai / div filho) assim o Absolute ficará dentro dela.

Lembre sempre, toda que você quiser criar um elemento com absolute você deve criar um elemento com position relative para deixar o abosulte ali dentro e evitar que ele fique solto na tela movendo para todo canto.
